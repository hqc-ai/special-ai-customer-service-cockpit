# Human Approval Pattern

Approval is required when an action may create financial, legal, contractual,
security, privacy, customer or reputational impact.

## Approval request

An approval request should present:

- proposed action;
- business purpose;
- affected customer, system or record;
- relevant evidence;
- expected impact;
- alternatives;
- timeout behavior;
- requester agent and accountable owner.

## Decisions

- Approve once.
- Approve with conditions.
- Reject.
- Return for correction.
- Take over manually.

Approval records should be linked to the resulting action and audit event.
