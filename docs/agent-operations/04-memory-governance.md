# Memory Governance

Agent memory is governed information, not an unrestricted transcript archive.

## Memory classes

- Working memory: temporary task state.
- Operational memory: approved facts used across sessions.
- Knowledge memory: sourced organizational knowledge.
- Lesson memory: reviewed improvement derived from prior outcomes.

## Required metadata

- source;
- owner;
- scope;
- creation date;
- review date;
- sensitivity;
- retention rule;
- confidence or validation status.

## User and administrator rights

Authorized users should be able to inspect, correct, retire or delete governed
memory according to policy and applicable obligations.

Private chain-of-thought or hidden model reasoning must not be treated as a
business record.
